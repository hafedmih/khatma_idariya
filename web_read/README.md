# الختمة الإدارية — نسخة القراءة للويب

نسخة ويب ثابتة (static) لعرض **ورد اليوم** من الختمة الإدارية: الأحزاب والأثمان المقررة لأي تاريخ،
مع **اقرأ** (مصحف PDF من Google Drive داخل الصفحة) و**استمع** (تلاوة يوتيوب داخل الصفحة).
لا خادم، لا تسجيل دخول، لا تتبّع — ملفات ثابتة فقط.

## الملفات

| الملف | الوصف |
|------|-------|
| `index.html` | الصفحة الرئيسية |
| `styles.css` | الثيم (ألوان التطبيق: أخضر/ذهبي، RTL) |
| `calculator.js` | خوارزمية الورد — منقولة حرفياً من `lib/services/khatma_calculator.dart` |
| `data.js` | بيانات الأحزاب الـ٦٠ + الأثمان + روابط PDF/YouTube (مولّدة من `assets/ahzab.json`) |
| `app.js` | منطق الواجهة |
| `favicon.png` | الأيقونة |

## المميزات

- 📅 ورد اليوم لأي تاريخ (مع منتقي تاريخ)
- 📖 بطاقات الأحزاب بألوانها الثلاثة + توسيع لعرض الأثمان الثمانية وفواتيحها
- 📄 **اقرأ** — عرض PDF داخل الصفحة (Google Drive preview) مع رابط فتح في نافذة جديدة
- 🎧 **استمع** — مشغّل يوتيوب مدمج
- 🗓️ معاينة الأسبوع، المصحف الكامل (٦٠ حزباً)، ليالي الختمة
- 🌙 بانر يوم الجمعة (سورة الكهف)
- ⤴ مشاركة ورد اليوم (Web Share / نسخ)

## التشغيل محلياً

افتح `index.html` مباشرةً في المتصفح، أو شغّل خادماً بسيطاً:

```bash
cd web_read
python -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

انسخ محتويات هذا المجلد إلى موقع النشر، مثلاً:

- **خيار أ:** ضعها في `docs/wird/` بالمستودع، ثم فعّل GitHub Pages من فرع `main` ومجلد `/docs`.
  ستكون متاحة على `https://<user>.github.io/<repo>/wird/` (صفحة الخصوصية تبقى في `docs/index.html`).
- **خيار ب:** ادفعها إلى فرع `gh-pages` كجذر للموقع.

كل الروابط الخارجية (خطوط Google، معاينة Drive، تضمين YouTube) تعمل عبر HTTPS على GitHub Pages.

## تحديث البيانات

عند تغيير `assets/ahzab.json`، أعد توليد `data.js`:

```bash
python -c "import json,io; d=json.load(io.open('assets/ahzab.json',encoding='utf-8-sig')); \
io.open('web_read/data.js','w',encoding='utf-8').write('window.AHZAB = '+json.dumps(d,ensure_ascii=False)+';')"
```
